# Code City 3D Visualizer — VS Code Extension

Visualize your code as a **3D city** using the Code City metaphor:
- **Classes** → Buildings (height = methods, width = fields)
- **Inheritance families** → Districts with shared colors & roof styles
- **Complexity** → Building height & color intensity

Supports **Python**, **PHP**, and **C#**.

---

## Setup (First Time)

```bash
# 1. Install dependencies
npm install

# 2. Bundle the webview
npm run build
```

That's it. Now open the extension in VS Code:

```
F5  →  Extension Development Host
```

---

## Usage

| Action | How |
|--------|-----|
| Open city view | `Ctrl+Shift+V` (Mac: `Cmd+Shift+V`) |
| Refresh manually | Command Palette → **Code City: Refresh** |
| Auto-refresh | Happens on every **Save** |

**Controls in the 3D view:**
- 🖱 **Left drag** — orbit / rotate
- 🖱 **Scroll** — zoom in/out
- 🖱 **Right drag** — pan

## Build for Distribution

```bash
npm install -g @vscode/vsce
npm run package
# → produces code-city-visualizer-1.0.0.vsix
```

Install the `.vsix`:
```
Extensions panel → ··· → Install from VSIX
```

## Project Structure

```
code-city-visualizer/
├── extension.js          ← VS Code entry point (Node.js / CommonJS)
├── webview-provider.js   ← Manages the webview panel
├── package.json          ← Extension manifest + build scripts
├── vite.config.js        ← Bundles src/ → dist/webview.js
├── media/
│   └── webview.css       ← Styles for the panel UI
├── src/
│   ├── webview.js        ← Three.js scene + OrbitControls (entry for Vite)
│   ├── Visualizer.js     ← Core orchestrator
│   ├── CodeParser.js     ← Python / PHP / C# parser
│   ├── VisualizationEngine.js  ← Routes to city or flowchart view
│   ├── CodeCityVisualizer.js   ← The city metaphor renderer
│   └── FlowchartEngine.js      ← Flowchart fallback
└── dist/
    └── webview.js        ← ← ← Generated by `npm run build` (don't edit)
```
